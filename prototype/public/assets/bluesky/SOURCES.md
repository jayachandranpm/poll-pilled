# Bluesky design assets

- Font: the InterVariable file observed in the live Bluesky app, bundled locally. `OFL-Inter.txt` preserves the font license.
- Icons: unmodified path data extracted from the official Bluesky Social `social-app/src/components/icons` SVG factories. MIT notice preserved in `LICENSE`. `src/blueskyIcons.js` maps Poll Pilled features to this icon family.
- Palette: official `@bsky.app/alf` 0.1.15 tokens, corroborated against computed styles of bsky.app.
- No Bluesky user posts, personal avatars, account data, butterfly branding, or third-party photography are included in the Poll Pilled fixtures. Existing Poll Pilled media and anonymous identities are retained.
- Screenshots and computed measurements in `qa/bluesky/source` document the design reference; they are not shipped UI assets.
